Google Calendar Setup — One-Time

  1. Go to console.cloud.google.com and create a project
  2. Enable the Google Calendar API
  3. Create an OAuth 2.0 Client ID (Web Application type)
  4. Add https://royal-energy-alchemy.netlify.app as an Authorized JavaScript Origin
  5. Copy the Client ID and paste it into GCAL_CLIENT_ID in dashboard.html

This only needs to be done once. After that, the Connect button will work every time.
