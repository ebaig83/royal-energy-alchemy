Google Calendar Setup — One-Time

  1. Go to console.cloud.google.com and create a project
  2. Enable the Google Calendar API
  3. Create an OAuth 2.0 Client ID (Web Application type)
  4. Add https://royal-energy-alchemy.netlify.app as an Authorized JavaScript Origin
  5. Copy the Client ID and paste it into GCAL_CLIENT_ID in dashboard.html

This only needs to be done once. After that, the Connect button will work every time.

Sync Appointments

Pull live appointments from Square and booking requests from your website directly into the dashboard. Existing records are never duplicated — only new entries are added.

⬡ Website Booking Requests

Pulls form submissions from your website's booking contact form (Netlify Forms). Requires NETLIFY_ACCESS_TOKEN in Netlify env vars. Imported as Pending — confirm each one manually.

One-Time Setup — Netlify Environment Variables

Go to Netlify → royal-energy-alchemy → Site Settings → Environment Variables and add:

SQUARE_ACCESS_TOKENSquare Developer → Your App → Production → Access Token
NETLIFY_ACCESS_TOKENNetlify → User Settings → Applications → Personal Access Tokens → New token

After adding env vars, redeploy the site once. Tokens are stored server-side only — never visible in the browser.
